# HangmanGame

## Overview
Short description: A command-line Hangman game in C++ demonstrating conditionals, loops, functions, classes, and STL containers. Loads words from words.txt and saves results to scores.txt.

## Features
- Word list loaded from `words.txt`.
- Save game results to `scores.txt`.
- Uses class `HangmanGame` and STL containers.
- Clear console UI.
